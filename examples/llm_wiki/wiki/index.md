# Index

The catalog of every page in this wiki. Maintained on every ingest.

Pages are flat — `wiki/<slug>.md`, one kebab-case file each, no subdirectories.
What kind of page it is lives in its `type:` frontmatter, and the headings
below are how you find it. That is the same job a folder tree would do, without
making a link care where the file sits.

Every operation on this wiki is recorded in `logs.md`.
