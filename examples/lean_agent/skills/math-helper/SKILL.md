# Math Helper Skill

Use this skill when handling mathematical calculations, unit conversions, or algorithmic steps:
1. Always write out mathematical formulas before substituting values.
2. For multi-step calculations, verify intermediate results step-by-step.
3. If necessary, execute a short Python one-liner via `exec_command` to verify precision.
